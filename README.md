# Zomi Dictionary — Complete Community Edition v5

This complete website includes 1,366 **unverified research candidates** and a live **Contribute a Word** link to your Google Form. The Google Form collects suggestions in your private response sheet; approval and publishing are manual.

## Upload to GitHub Pages
1. Extract this ZIP.
2. Open https://github.com/singkkhai/zomidictionary/upload/zomilexicon
3. Upload the **eight files inside this folder**, not the ZIP itself. Replace older files as needed.
4. Commit changes, wait for Pages deployment, and refresh https://zomidictionary.singkhai.com with Ctrl+Shift+R.

The CNAME is included for the existing custom domain.

Google Form: https://docs.google.com/forms/d/e/1FAIpQLSc1OMENfn48CQvFVHzHLd7V-z6pbcpCWxDrd_cEhC8fu5ojDg/viewform

Never label the 1,366 candidate entries as independently verified. Approved submissions must be manually reviewed and added to approved.json.
